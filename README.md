# SellMora website (one-page version)

সব পেজ একটাই `index.html`-এ আছে। মেনুতে ক্লিক করলে `#/about`, `#/services/ppc-management` এভাবে পেজ বদলায়।

## ফোল্ডার
- `index.html` — সব পেজের HTML (প্রতিটা পেজের শুরুতে `PAGE:` কমেন্ট আছে)
- `assets/css/style.css` — সব ডিজাইন, ২১টা ভাগে কমেন্ট করা
- `assets/js/main.js` — মেনু, অ্যানিমেশন, পেজ বদল, ফর্ম
- `assets/img/` — লোগো, favicon, টিমের ছবি

## Favicon বদলাতে
নিজের আইকনটা `favicon.png` নামে (নামে স্পেস ছাড়া) `assets/img/` ফোল্ডারে রেখে দিন, আগেরটা রিপ্লেস হয়ে যাবে।

## লাইভ করতে
এই ফোল্ডারের ভেতরের সব ফাইল হোস্টিংয়ের `public_html`-এ আপলোড করুন।
